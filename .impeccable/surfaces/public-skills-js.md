# Dinner micro-skill

Approved scope: extend Homeward with one autonomous dinner module. Pictured meal → three readiness checks → real-life attempt → private self-check → progress. Preserve existing workbook, no AI, browser first. Use existing meals and visual identity. Personal progress is separate from shared vision sessions; milestone sharing is deliberate.

## Direction contract

THESIS: One useful, resumable action at a time. The current task owns the screen; workbook administration stays secondary.

OWN-WORLD: Inherit DESIGN.md: paper, forest green, Georgia headings, native controls, flat bordered meal pictures. Restrained palette for a parent using a phone at home.

STORY: Choose a familiar meal, prepare without writing a plan, leave to cook, return to reflect. XP acknowledges practice; self-check describes confidence. No partner comparison.

FIRST VIEWPORT: Small Homeward header; narrow centred task column; question first, supporting sentence, two-column meal choices. Readiness uses three full-width checklist rows. Primary action directly follows each task. Progress and workbook link are quiet footer navigation.

FORM: User-approved narrow extension, direct code-led implementation. Concept roll not applicable: exact sequence and incumbent identity are pinned. Signature interaction: checking readiness updates the remaining count; finishing a practice gives a brief, reduced-motion-aware receipt.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

States: empty, choosing, preparing, ready, tried, completed, repeat; autosave pending/failed; stale-tab conflict; private/shared milestone. No AI, no additional modules, no avatars or mastery claims. Existing meal rasters retain provenance.
